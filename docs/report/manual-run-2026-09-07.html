How to read the ledgers

Each order carries an append-only ledger (order_events). A row with an arrow is a status change; a row without one is a fact worth auditing (a retry scheduled, a signature persisted, a duplicate ignored). The row and the status change are written in the same database transaction, so the story survives any crash. Actors: the listener (chain events), a worker (broker and settlement), the reconciler, or a replay.

The switch is a row in Postgres read by every worker before it claims work, so all replicas obey it at once. It is the operator's incident tool, and the same switch the circuit breaker throws after a burst of critical alerts.
